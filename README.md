## Objetivo do Projeto
Criar a estrutura inicial da API Web em Python com Flask para chamados de suporte de TI, configurando o gerenciamento de ambiente e dependências com `uv` e disponibilizando a rota inicial `GET /`.

## Instalação das Dependências
